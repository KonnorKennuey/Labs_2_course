# Лабораторная работа № 3 — вариант 4

Выполнена Python-часть: DummyJSON Comments + Posts, обогащение Users.
Основная таблица содержит одну строку на комментарий.

## Запуск

Требуется Python 3.11+ и доступ к https://dummyjson.com.
Откройте терминал в этой папке:

```powershell
python -m pip install -r requirements.txt
```

Откройте `lab_3.ipynb` в Jupyter или VS Code, выберите Python с установленными
зависимостями и выполните все ячейки сверху вниз. Рабочая папка ядра должна быть
этой папкой. Блокнот также определяет путь при запуске из корня репозитория
или `Data_mining`. Ключи API и переменные окружения не требуются.

Первый запуск собирает исходные данные, а второй внутри блокнота демонстрирует
инкрементальность. Если `state.json` и `data_clean.csv` уже существуют, оба
прогона добавят только комментарии с ID выше сохранённого водяного знака.
Для воспроизведения первого сбора используйте новую копию папки без
`state.json`, `data_clean.csv`, `data_raw.jsonl` и `collection_log.csv`.

## Файлы

- `lab_3.ipynb` — код, пояснения, результаты и графики.
- `data_raw.jsonl` — успешные сырые ответы страниц: один JSON-объект на строку,
  с ресурсом, номером прогона и временем получения.
- `data_clean.csv` — комментарии с данными поста и авторов.
- `collection_log.csv` — журнал каждой попытки HTTP-запроса, включая ошибки.
- `state.json` — максимальный сохранённый ID комментария и время обновления.
- `post_tags.csv` — развёрнутый массив тегов постов.
- `quality.csv`, `business_checks.csv`, `outliers.csv` — проверки качества.
- `posts_activity.csv`, `authors_activity.csv`, `activity.png` — анализ активности.
- `run_metrics.csv` — измерения двух прогонов.
- `report.md` — отчёт; поля ФИО, группы, no-code и субъективной оценки заполняются студентом.

Водяной знак рассчитан на добавление новых комментариев с возрастающим ID.
API не предоставляет дату изменения комментария; обновления и удаления старых
записей этим учебным алгоритмом не отслеживаются. При повторе страницы снова
читаются для поиска новых ID: инкрементальность относится к сохранению данных,
а не к сокращению сетевого трафика. Журнал и сырые ответы дописываются.
